# Job Application Automation System

A Python-based automation tool that streamlines the job application process by sending personalized emails with resume attachments to multiple companies.

---

## Features

- Automated bulk email sending
- Personalized job application emails
- Resume attachment support
- CSV-based recruiter/job management
- SMTP email integration
- Delivery status tracking

---

## Tech Stack

- Python
- Pandas
- SMTP
- EmailMessage
